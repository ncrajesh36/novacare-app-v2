What this is

Mobile-framed healthcare companion: Rosa (patient) manages reminders, BP capture, and symptom chat; Carlos (sponsor) sees alerts and tops up a wallet.

  • UI repo: novacare-app-v2
  • Chat API: novacare-backend
  • Deployed UI: Vercel

How to run

  1. npm install && npm run dev → Vite UI (~5173)
  2. In novacare-backend: uvicorn main:app --reload --port 8000
  3. Point src/Chat.jsx at http://localhost:8000/chat (or set the base above and probe)
  4. This overview: python3 -m http.server 8085 in overview/
